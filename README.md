# Window Split

Organiza tus aplicaciones de Windows en **grupos**: varias ventanas que se acomodan, se mueven, se muestran y se ocultan juntas, con una sola barra y un solo botón en la barra de tareas.

## Funciones
- **Grupos de apps** con nombre propio y apodos para cada ventana.
- **Acomodos**: Columnas, Filas, Cuadrícula, Principal + lateral o Libre, con vista previa animada antes de aplicarlos.
- **Barra de grupo** con minimizar, maximizar y cerrar, como cualquier ventana.
- **Un solo botón en la barra de tareas** por grupo, con vista previa en Alt+Tab.
- **Ventanas ancladas**: arrastra una app sobre otra para intercambiarlas; nunca se despegan del grupo.
- **Grupos guardados** que se reabren con las mismas apps.
- **Actualizaciones automáticas.**

## Instalar
1. En **Releases**, descarga `WindowSplit-win-Setup.exe` de la versión más reciente.
2. Ábrelo. Se instala para tu usuario, sin permisos de administrador, y aparece en la bandeja del sistema.
3. Crea tu primer grupo con **Ctrl+Win+G**.

Si Windows muestra "Windows protegió su PC", pulsa *Más información* → *Ejecutar de todas formas*.

## Requisitos
Windows 10 u 11 de 64 bits.

## Actualizaciones
Window Split busca versiones nuevas automáticamente, las descarga en segundo plano y las instala al cerrarse. También puedes instalarlas al momento desde el menú de la bandeja: *Reiniciar y actualizar*.

## Desinstalar
*Configuración → Aplicaciones → Aplicaciones instaladas → Window Split → Desinstalar*.
