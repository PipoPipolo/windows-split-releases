# Window Split — descargas

Este repositorio solo contiene los instaladores y paquetes de actualización de **Window Split** (el código fuente es privado).

## Instalar
1. Ve a **Releases** y descarga `WindowSplit-win-Setup.exe` de la versión más reciente.
2. Ábrelo. Se instala para tu usuario (no pide administrador) y queda en la bandeja del sistema.
3. Si Windows muestra "Windows protegió su PC": *Más información* → *Ejecutar de todas formas* (la app aún no está firmada digitalmente).

## Actualizaciones
La app comprueba este repositorio al arrancar y cada 4 horas, descarga la versión nueva en segundo plano y la instala al cerrarse (o al instante con *Reiniciar y actualizar* en el menú de la bandeja).

## Desinstalar
*Configuración → Aplicaciones → Aplicaciones instaladas → Window Split → Desinstalar*.
